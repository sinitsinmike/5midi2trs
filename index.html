DIY MIDI Adapter

5MIDI2TRS

5-pin DIN MIDI ↔ 3.5 mm TRS MIDI A / B

Простой MIDI-переходник

5MIDI2TRS — компактный и очень бюджетный двунаправленный MIDI-адаптер для соединения классического 5-pin DIN MIDI с оборудованием, использующим 3.5 мм TRS MIDI.

Основная задача устройства — сделать подключение максимально простым: использовать обычный кабель с разъёмами 3.5 мм и при необходимости переключить вариант распайки TRS MIDI непосредственно на корпусе.

5-pin DIN MIDI Классический MIDI-разъём для совместимости с большим количеством синтезаторов, клавиатур и другого оборудования.
3.5 mm TRS MIDI Компактный формат MIDI-подключения, широко используемый в небольших устройствах.
Type A / Type B Переключение варианта TRS MIDI одной кнопкой.
Двунаправленная работа Адаптер предназначен для работы в обоих направлениях MIDI-соединения.

Зачем он нужен?

В традиционном MIDI используется 5-контактный DIN-разъём. В компактных современных MIDI-устройствах часто применяется 3.5 мм TRS-разъём. При этом встречаются два варианта распайки — TRS Type A и TRS Type B.

5MIDI2TRS объединяет эти варианты в одном небольшом устройстве. Нужный тип выбирается кнопкой на корпусе, поэтому для смены режима не требуется переделывать адаптер или искать другой переходник.

5-pin DIN MIDI   ↔   5MIDI2TRS   ↔   3.5 mm TRS MIDI
TRS Type A ↔ Type B — переключается кнопкой

Обычные 3.5 мм кабели

Устройство позволяет использовать распространённые кабели с разъёмами 3.5 mm TRS (stereo Jack) для MIDI-соединения. Это удобно для компактных синтезаторов, контроллеров и DIY-устройств, где полноразмерный DIN-разъём может занимать много места.

Для подключения MIDI необходимо использовать подходящий TRS-кабель с контактами Tip / Ring / Sleeve. Режим Type A или Type B выбирается в соответствии с подключаемым оборудованием.

Двунаправленное подключение

Адаптер не преобразует MIDI-команды и не является MIDI-контроллером. Его задача — обеспечить физическое соединение между двумя форматами MIDI-разъёмов.

  • 5-pin DIN → 3.5 mm TRS MIDI
  • 3.5 mm TRS MIDI → 5-pin DIN
  • TRS Type A / Type B — выбирается переключателем
