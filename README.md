# TRS MIDI Adapter

## 5-pin DIN ↔ TRS MIDI A / TRS MIDI B

Простой и бюджетный двунаправленный MIDI-адаптер для подключения
оборудования с классическим **5-pin DIN MIDI** к устройствам с **3,5 мм
TRS MIDI**.

Адаптер позволяет использовать обычные кабели 3,5 мм Jack для передачи
MIDI и переключать тип распайки **TRS MIDI Type A / Type B** одной
кнопкой.

## Возможности

-   **5-pin DIN MIDI ↔ 3,5 мм TRS MIDI**
-   Двунаправленная работа: MIDI IN / MIDI OUT
-   Переключение **TRS MIDI Type A / Type B** кнопкой на корпусе
-   Возможность использовать обычные доступные **3,5 мм
    стерео-аудиокабели**
-   Компактный и лёгкий корпус
-   Простая и недорогая конструкция
-   Не требует программирования или настройки
-   Подходит для MIDI-клавиатур, синтезаторов, контроллеров и другого
    MIDI-оборудования

## Зачем нужен этот адаптер?

В классическом MIDI используется круглый 5-контактный DIN-разъём. В
компактных современных устройствах всё чаще применяется **3,5 мм TRS
MIDI**.

При этом существуют два распространённых варианта распайки TRS MIDI:

-   **Type A**
-   **Type B**

Из-за этого обычный кабель или адаптер, подходящий для одного
устройства, может не работать с другим.

Этот адаптер решает проблему простым способом: нужный тип TRS выбирается
**переключателем на корпусе**.

Таким образом, можно соединить:

``` text
MIDI устройство с 5-pin DIN
          ↕
    TRS MIDI Adapter
          ↕
MIDI устройство с 3.5 mm TRS
```

## Двунаправленная работа

Адаптер является **пассивным MIDI-переходником по назначению
подключения** и рассчитан на работу в обоих направлениях:

``` text
5-pin DIN → TRS MIDI
```

и

``` text
TRS MIDI → 5-pin DIN
```

Это позволяет использовать его как для передачи MIDI **OUT → IN**, так и
для обратного направления.

## TRS Type A / Type B

Кнопка на корпусе переключает распайку TRS MIDI:

``` text
[ TRS A / B ]

   A  ←→  B
```

Это позволяет использовать адаптер с оборудованием, рассчитанным на
разные варианты TRS MIDI, без замены внутренней распайки и без
специального кабеля.

## Использование обычных 3,5 мм кабелей

Одно из основных преимуществ такого решения --- возможность применять
распространённые кабели с разъёмами **3,5 мм TRS (stereo Jack)**.

Это особенно удобно для компактных MIDI-устройств, где полноразмерный
5-pin DIN занимает много места.

> Важно: для MIDI следует использовать именно подходящий **TRS-кабель с
> тремя контактами (Tip/Ring/Sleeve)**. Тип A или Type B выбирается в
> соответствии с подключаемым устройством.

## Конструкция

Устройство выполнено в компактном корпусе и содержит:

-   разъём **5-pin DIN MIDI**;
-   разъёмы **3,5 мм TRS MIDI**;
-   переключатель **TRS A / TRS B**.

Конструкция рассчитана прежде всего на простоту, компактность и низкую
стоимость.

## Для кого

Адаптер может быть полезен:

-   владельцам компактных синтезаторов;
-   пользователям MIDI-контроллеров;
-   музыкантам и звукорежиссёрам;
-   DIY-разработчикам MIDI-оборудования;
-   при сборке домашних и концертных MIDI-систем;
-   для подключения старого оборудования с DIN MIDI к современным
    устройствам с TRS MIDI.

## Особенности проекта

Это не MIDI-конвертер и не самостоятельное MIDI-устройство с
микроконтроллером.

Он не изменяет MIDI-команды и не обрабатывает MIDI-данные программно.
Его задача --- обеспечить удобное физическое соединение между **5-pin
DIN MIDI** и **3,5 мм TRS MIDI**, включая выбор типа **A/B**.

**Простой переходник для реальной MIDI-системы --- без лишней
электроники и без лишних настроек.**
